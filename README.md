# وظيفتي بوت - Job Bot

بوت تيليجرام ذكي للوظائف مع نظام تقديم تلقائي وذكاء اصطناعي للمطابقة.

## المميزات

- 🔍 بحث عن وظائف حسب التخصص والمدينة
- 🤖 تقديم تلقائي على الوظائف
- 💰 نظام نقاط واشتراكات (3 نقاط مجانية يومياً)
- 🎯 مطابقة ذكية بين الباحثين والشركات
- 📊 لوحة تحكم للأدمن

## الأوامر

| الأمر | الوصف |
|-------|-------|
| `/start` | بدء استخدام البوت |
| `/jobs` | عرض آخر الوظائف |
| `/applications` | عرض تقديماتي |
| `/settings` | إعدادات الحساب |
| `/subscriptions` | باقات الاشتراك |
| `/support` | الدعم الفني |
| `/unsubscribe` | إلغاء الاشتراك |
